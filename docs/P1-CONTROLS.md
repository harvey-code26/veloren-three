## 验收方式

1. WASD、B、Shift、L、0、.、, 与鼠标中键逐个验证；R 不再重置。
2. 从跑步切到步行/潜行，观察速度区别。
3. 向前移动时开 L，转动镜头，人物保持原行动方向；关 L 恢复原来的观察方向。
4. 按 0 进入第一人称，确认人物头部不遮挡画面；滚轮切回第三人称。
5. 在门框/墙角观察相机遮挡回缩；无穿模与不可控视角。
6. 记录与原作的视角灵敏度、第三人称转身速度、跑跳、翻滚距离差异，后续校准。
