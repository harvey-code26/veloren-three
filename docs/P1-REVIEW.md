# P1 — 核心运动测试场 · 体验与验证说明

当前状态：**规则测试与 CI 生产构建通过；等待浏览器实际试玩验证**。原作参考基线：`cd75076c`。本版不包含体素地形或原作资源。

## 我们做了什么

- `FixedStepClock`：60 Hz 规则更新，渲染只读取快照并插值；长时间卡顿最多补偿 5 步。
- `InputController`：将键鼠状态转换为按 tick 编号的输入；跳跃使用一次性事件；失焦清空按键。
- `Simulation`：角色位置、速度、地面状态、重力、走跳、冲刺；规则模块不依赖 Three.js。
- `CollisionWorld`：轴向扫掠 AABB 碰撞，区分实际的碰撞数据与可见网格；P2 将替换数据源。
- `ThirdPersonCamera`：第三人称视角，检测前方障碍并缩短相机距离。
- `TestScene`：同一组测试用碰撞盒同时生成物理场与可见障碍。

## 操作

启动：`npm install && npm run dev`（Node.js 22+）。画面点击锁定鼠标，WASD 移动、Shift 冲刺、空格跳、Esc 解锁、Q/E 备用转向、滚轮缩放、R 返回出生点、F3 切换调试指标。

推荐路线：①出生位置连续前进并撞上低墙；②沿低墙绕行；③往左去矮台阶跳上去；④走入狭长通道；⑤到蓝色门框下测试镜头和头顶碰撞；⑥按 R 重置；⑦按 F3 观察位置与接地。

## 当前明确的简化

- 角色是原创几何占位模型，不是 Veloren 资产；不做角色动作原版还原。
- 没有自动上台阶、坡面和滑翔；这些分别在 P1 反馈与 P4 中评估。
- 碰撞体采用 AABB，后续如果手感要求再比较胶囊体。
- 对时间、坐标与碰撞的自动化验证已建立；完整浏览器视觉与性能验收仍是独立阶段。
