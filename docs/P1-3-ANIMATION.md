# P1.3 — 人物运动与原作资源的浏览器验收

这一轮不扩展世界或战斗，只修正原版 VOX 人物在 P1 测试场中的动画结构，并增加自动浏览器截图。

## 本轮改动

- 移动速度驱动的步态相位：按实际位移距离推动腿部交替，而非按累计秒数重复快速切换
- 左右脚始终属于原来的骨骼节点；足部抬起量非负，避免交叉和穿地风险
- 待机独立呼吸，即使完全静止仍保持微动作
- 区分起跳、下落、落地过渡、行走、奔跑、潜行和翻滚
- 翻滚以身体中部旋转，而不是绕脚底打转
- 人物平滑转向：沿最短角度插值，减少瞬时 180 度跳转
- 自由观察继续保持相机与移动朝向分离；第一人称与现有按键不变
- F3 调试面板增加动作状态、步态相位与人物朝向

## 技术验证

- 新增纯计算步态测试：不同帧率的位移相位、一左一右步态、倒退、起落、翻滚完整周期、跨 ±π 的平滑转身和动作重置
- CI `Validate` 现在运行 Chromium 软件 WebGL 的真实网页加载，验证原版 VOX 加载成功、移动、按 0 切换视角，上传三张截图供复核
- 自动化截图能证明资源加载和渲染管线工作，但无法独立证明它已经与 Veloren 原版动作完全一致

## 需要继续人工比较的点

- 人物侧身与后退移动时的骨架造型
- 快跑时脚尖是否穿过地形、转身期间鞋子是否打转
- 原作翻滚对应的具体动画时间线、装备与姿态
- 滑翔、攀爬、战斗动作尚未接入
- 手机与 Safari 兼容性尚未验收

## 浏览器截图复核：镜头近距修复

首次 Chromium 截图发现，贴近障碍物时第三人称相机的碰撞射线会把视距压到约 0.2m，导致原版人物背部占满视野。修复为：距离缩短立即响应遮挡，远离障碍后逐渐回到设定距离；当实际镜头距小于 1.75m 时暂时隐藏第三人称人物。此外忽略鼠标锁定后的第一次异常位移增量，以减少初次点击后的视角跳变。F3 展示实际镜头距离与自动隐藏状态。需以更新后的自动截图复核。

## P1.3 第二次浏览器回归

初版真实截图还暴露了锁定鼠标后向左突转约 90° 的风险，触发相机贴墙回缩并短时间隐藏了人物。本轮增加首次锁定 180ms 内的位移保护和近距离第一人称退避，浏览器回归会断言默认前进不发生异常大角度旋转。这个保护只拦截初次捕获鼠标时的移动，不改变后续正常转向键位。

## 验证分离

自动 Chromium 在合成的 pointer-lock 点击后产生了异常大鼠标位移，造成角色偏转。为避免把自动化鼠标行为误判为 W 键移动错误，P1.3 的浏览器截图回归改为在鼠标静止的情况下验证直线移动和第一人称切换；鼠标锁定仍由独立的实机操作验收。输入层额外过滤单事件绝对值超过 120px 的异常位移，保留真实鼠标移动灵敏度。该阈值与 180ms 保护属于浏览器版的稳健性措施，非 Veloren 原作参数。
